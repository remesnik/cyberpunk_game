# Roadmap

Planned vertical slices, intentionally not implemented in this bootstrap:

1. **Graph traversal slice** — a small host graph, route selection, discrete movement cost, and a readable abstract graph display.
2. **Network discovery slice** — scan hosts and services, reveal topology, and inspect incomplete route information.
3. **Program execution slice** — equip and run a small set of data-driven programs with costs and cooldowns.
4. **Hacking slice** — interact with a service, complete a compact intrusion loop, and unlock access.
5. **ICE avoidance slice** — graph-based ICE movement, detection states, trace pressure, route prediction, and alarms.
6. **Security encounter slice** — one hostile defensive program, tactical program choices, damage, and recovery.
7. **Integrated mission slice** — enter a network, discover a target, bypass security, extract data, and escape.
8. **Persistence and polish** — save progression, accessibility options, performance budgets, audio, and visual refinement.
